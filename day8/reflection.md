# Reflection

**The most difficult concept and how I overcame it.**
The hardest concept was the gap between working code on my computer and work that is actually on GitHub. My Project 1 scored 68% because I had written validation, delete, search and localStorage in script.js but never committed and pushed it, so GitHub still held the old version. Later, an unsaved file pushed as empty. I overcame this by checking git status before every commit, saving all files with Ctrl + S, and opening the file on GitHub afterwards to confirm the content is really there.

**What I would improve in my capstone.**
Based on the Project 1 feedback, I would improve my testing and my commit history. I would commit after finishing each task instead of at the end, so the history shows real progress, and I would test the live GitHub version before submitting. In Project 2, I would also make the API client stronger by handling real errors from a backend that stores notes properly, instead of faking deletes for notes JSONPlaceholder never saved.

**What I will learn next.**
Next I want to learn a backend language and connect QuickNotes to a real database so notes are stored on a server instead of in localStorage. After that, I want to deploy it on AWS, which fits my cloud computing goals.
