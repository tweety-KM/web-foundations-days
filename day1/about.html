About QuickNotes

QuickNotes is a simple web app for capturing ideas, reminders and to-dos the moment they come to mind. It keeps your notes in one place so you can find and review them quickly.

How to use QuickNotes

  1. Open QuickNotes and click the note box.
  2. Type your note, then press Save.
  3. Review your saved notes in the list below the box.
  4. Edit or delete a note when it is no longer needed.

Features

  • Fast note capture
  • Simple, distraction-free layout
  • Easy editing and deleting
  • Keyboard shortcuts

Keyboard shortcuts

Shortcut Action
Ctrl + N Create a new note
Ctrl + S Save the current note
Ctrl + D Delete the current note
